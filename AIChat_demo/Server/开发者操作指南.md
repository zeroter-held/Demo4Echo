# Echo AIChat 开发者操作指南

## 1. 架构与前提

```text
开发板 main ──USB 网络/WebSocket──> Windows AIChat Server:8000 ──> 阿里云百炼
```

- 开发板 USB 网卡：`172.32.0.93`
- Windows USB 网卡：`172.32.0.100`
- WebSocket 端口：`8000`
- 两端访问口令：自行设置私有令牌，两端必须一致。
- Windows 电脑需要联网；开发板 Wi-Fi 用于 NTP、天气等板端联网功能。

## 2. Windows：启动 AIChat Server

在 **PowerShell** 执行：

```powershell
cd "E:\360MoveData\Users\22806\Desktop\Echo robot\Demo4Echo\AIChat_demo\Server"
.\.venv\Scripts\Activate.ps1
$env:DASHSCOPE_API_KEY = Read-Host "请输入百炼 API Key"
python .\main.py --access_token="你的私有令牌"
```

- 输入的是自己的百炼 `sk-...` 或 `sk-ws-...` Key；不要把 Key 写进源码、截图或提交到 Git。
- 成功标志：

```text
WebSocket server started on 0.0.0.0:8000
```

- 另开一个 PowerShell 可检查端口：

```powershell
Test-NetConnection 127.0.0.1 -Port 8000
```

看到 `TcpTestSucceeded : True` 即服务端已监听。

## 3. 开发板：配置 AIChat

通过 MobaXterm 登录开发板，在 `/root/bin/system_para.conf` 中确认：

```ini
AIChat_server_url=172.32.0.100
AIChat_server_port=8000
AIChat_server_token=你的私有令牌
AIChat_protocol_version=2
auto_location=false
```

说明：

- `server_url` 是 Windows USB 网卡地址；不是 Wi-Fi 地址。
- `server_token` 必须与 Windows 的 `--access_token` 相同。
- `auto_location=false` 可避免当前固件在自动定位失败时异常退出。
- 当前 Windows Server 从 `DASHSCOPE_API_KEY` 读取百炼 Key；该 Key 是服务端实际调用百炼所必需的配置。

确认 USB 网络：

```sh
ping -c 3 172.32.0.100
```

## 4. 启动与停止开发板程序

首次排查建议前台运行：

```sh
cd /root/bin
./main
```

稳定后使用后台运行：

```sh
cd /root/bin
nohup ./main > /tmp/echo-main.log 2>&1 &
echo $!
```

常用命令：

```sh
ps | grep '[m]ain'                 # 查看真实 main 进程
tail -f /tmp/echo-main.log          # 查看后台日志
kill <PID>                          # 停止指定 ./main 进程
```

显示为 `[main]` 的条目是僵尸进程，不能用 `kill` 清除，通常可忽略；只操作显示为 `./main` 的 PID。

## 5. 成功链路日志

Windows 服务端依次出现以下日志，说明板端已成功连接：

```text
Client connected
Authentication successful
Received hello message with audio params
```

`Client disconnected` 表示板端 `main` 停止或网络断开。

## 6. Wi-Fi 恢复（开发板）

若 `wpa_cli -i wlan0 status` 报控制接口不存在，说明 `wpa_supplicant` 未运行：

```sh
ifconfig wlan0 up
mkdir -p /var/run/wpa_supplicant
wpa_supplicant -B -c /etc/wpa_supplicant.conf -i wlan0
sleep 5
wpa_cli -i wlan0 status
```

连接成功应显示 `wpa_state=COMPLETED`。之后获取 IP：

```sh
udhcpc -i wlan0
ifconfig wlan0
```

## 7. 已验证的语音能力

- 普通问答：语音识别 → 通义千问 → 语音播报。
- 运动指令：板端注册了 `robot_move`，可试“向前走两秒”“左转一秒”。
- 结束对话：可说“再见”“拜拜”“晚安”。

唤醒词由开发板本地固件/模型决定，不在 Windows Server 代码中配置；默认固件可先尝试说 `Echo`。
